## Prerequisites

- Python 3.11 or newer
- [uv](https://docs.astral.sh/uv/)

SQLite works locally without another service. PostgreSQL and Redis are recommended for production.

## Local Setup

```bash
git clone git@github.com:level09/ziglag.git
cd ziglag
./setup.sh
uv run quart create-db
uv run quart run --port 5001
```

Open `http://localhost:5001`. The first visit opens `/setup` so you can create the administrator account.

You can also create the account from the CLI:

```bash
uv run quart install -e admin@example.com -p 'replace-this-password'
```

## Verify the Checkout

```bash
uv sync --extra dev
uv run ruff check .
uv run ruff format --check .
uv run python -m unittest discover -s tests -v
uv run python checks.py
uv run quart verify --json
```

## Docker

```bash
docker compose up --build
```

The compose stack includes PostgreSQL, Redis, Nginx, and the ZigLag application.
