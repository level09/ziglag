## Overview

ZigLag is a self-hosted invoicing application for freelancers and small businesses. It uses stk 13.4.1 for async Quart, authentication, database migrations, WebSockets, operational commands, and production deployment.

## Core Workflow

1. Store client contact and VAT details.
2. Create a draft with line items, service period, and tax treatment.
3. Choose Precision, Branded, or Editorial presentation.
4. Issue or send the invoice.
5. Preserve the generated PDF while tracking views and payments.
6. Cancel incorrect issued invoices without deleting their record.

## Security and Operations

stk supplies session authentication, TOTP, WebAuthn, OAuth, recovery codes, account lockout, rate limiting, Alembic, verification commands, browser smoke testing, and a production deploy script.

Useful commands:

```bash
uv run quart inspect context --json
uv run quart verify --json
uv run quart smoke --json
uv run quart new <module>
```
